Projekti on 2 opintopisteen laajuinen ohjelmistoprojekti Ohjelmointi II -kurssilla, minkä vuoksi se
on tarkoituksella pidetty yksinkertaisena.
Marshmallow Game on yksinkertainen, interaktiivinen pelisovellus, jossa käyttäjä paistaa
vaahtokarkin nuotiolla. Peli etenee vaiheittain painikkeita painamalla: ensin rakennetaan nuotio,
sen jälkeen sytytetään tuli ja lopuksi vaahtokarkki paistetaan. Jokainen vaihe avautuu vasta
oikeassa järjestyksessä, mikä ohjaa käyttäjää etenemään pelissä oikein.
Sovellus on suunnattu kevyeksi ajanvietteeksi ja ohjelmointiharjoitukseksi. Sen potentiaalisia
käyttäjiä ovat esimerkiksi opiskelijat ja henkilöt, jotka haluavat kokeilla yksinkertaista
pelisovellusta graafisella käyttöliittymällä. Projekti on pidetty tarkoituksella selkeänä ja helposti
ymmärrettävänä.
